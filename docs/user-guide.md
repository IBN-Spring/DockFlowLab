# DockFlowLab 使用指南

本指南面向第一次做分子对接的使用者，不要求会写代码。界面按顺序分五步，
每一步完成后才能自然进入下一步；对接完成后还有一个可选的“PyMOL 渲染”页面，
用于把结果套用你自己的风格脚本导出图片。

## 开始之前

需要准备：

- 一个靶点结构文件（通常是 `.pdb` 或 `.cif`；蛋白、DNA/RNA、多肽或作为刚性靶点的小分子）
- 一个或多个候选分子文件（通常是 `.sdf`、`.mol2`、`.mol` 或 `.smi`）
- 一个空文件夹作为工作目录（建议放在非系统盘，例如 `D:\docking\项目名`）

如果没有结构文件，可以在“添加分子”页面里从公共数据库下载。

## 第 1 步：工作目录

程序启动后先选择工作目录：

- **新建项目**：选择一个空文件夹，输入容易辨认的项目名称。
- **打开已有项目**：选择以前创建的工作目录，程序会读取其中的 `project.json`。
- **最近项目**：从列表直接打开。

所有原始文件、准备后的结构、盒子设置、对接结果和报告都保存在这个目录里。
换电脑时整目录复制即可，不需要数据库或注册表。

## 第 2 步：添加分子

页面分为“靶点结构”和“候选分子”两栏：

- 可以拖放文件到虚线区域，也可以点击选择文件；支持一次添加多个。
- 添加后可以修改显示名称。名称只影响界面与报告，不会改动结构文件。
- 结构中的链、配体、金属离子等信息会显示在条目上，便于确认选对了文件。
- 每个条目会显示程序识别出的结构类型（蛋白质、多肽/短肽、核酸、小分子）。
- 点击“下载结构”可按 PDB ID、化合物名称、CID、SMILES 或 UniProt 登录号获取结构。

常见格式：

| 类型 | 推荐格式 | 说明 |
| --- | --- | --- |
| 靶点结构（蛋白/核酸/多肽） | PDB、mmCIF | 尽量包含完整链；缺失残基可由程序补全 |
| 靶点结构（小分子） | SDF、MOL、MOL2 | 小分子–小分子模式下作为刚性受体 |
| 候选分子 | SDF、MOL2、MOL | 建议包含三维坐标和氢原子；程序也会补氢与生成构象 |
| 已准备结构 | PDBQT | 可直接用于对接，但仍会做格式校验 |

一个 SDF 文件里如果有多个分子，请先拆分成单分子文件，否则程序只会处理第一个并给出提示。

## 第 3 步：检查与准备

点击“开始准备”后，程序会：

1. 识别结构类型：蛋白质、多肽/短肽、核酸（DNA/RNA）或小分子。
2. 对大分子靶点（蛋白、核酸、多肽）：移除不参与对接的水、多余离子，以及
   共晶配体所在的短链（包括肽类抑制剂中按标准氨基酸记录的那部分残基），
   补全缺失残基/原子，按 pH 7.4 加氢。
   例如 6LU7 的 N3 抑制剂横跨标准残基与非标准残基，程序会把整条链一起排除，
   避免配体碎片留在结合位点里。
3. 对小分子：读取结构、补氢、检查三维构象、做能量最小化，并用 Meeko 生成 PDBQT。
4. 校验生成的 PDBQT 是否包含有效坐标、原子类型和电荷。

如果候选分子实际上是蛋白质或多肽，准备阶段会直接拒绝，并提示这类大分子
配体对接不在本地实现。

条目状态的含意：

- **待处理**：还没有准备。
- **就绪**：可用于对接。
- **需注意**：已生成文件，但有警告（例如移除了金属离子、使用了 OpenBabel 回退）。
- **失败**：无法生成可用文件，右侧会写明原因。

准备工作是可重复的。修改原始文件后点击“重新准备”即可覆盖旧结果。重新准备
靶点后，旧的自动盒子会被丢弃，并在下次对接时按新受体重新计算；手动盒子会
保留。

## 第 4 步：设置对接

### 对接类型

不需要手动选择模式。程序会根据“靶点结构 + 候选分子”的类型自动判断：
蛋白–小分子、多肽–小分子、核酸–小分子、小分子–小分子。
结果表与报告中会写明每一组的对接类型。

以下组合本地不执行对接，界面会直接说明原因并给出替代工具，不会生成分数：

| 组合 | 原因与建议 |
| --- | --- |
| 蛋白质/多肽作为候选分子 | 大分子配体暂不支持；请用 ClusPro、HADDOCK、RosettaDock |
| 核酸–蛋白质/多肽/核酸 | 需要专门的核酸–大分子对接工具 |
| 小分子–蛋白质/多肽/核酸 | 请把大分子放在“靶点结构”一栏 |

### 对接引擎

程序内置三种接受同一套 PDBQT 输入的引擎，可在“搜索设置”顶部的“对接引擎”
中切换：

| 引擎 | 特点 | 适用情况 |
| --- | --- | --- |
| AutoDock Vina 1.2.7 | 标准引擎，最常被文献引用 | 默认 |
| QuickVina 2.1 | 基于 Vina 1.1.2 的加速版，评分相同、搜索更快 | Vina 长时间无输出，或想加速初筛 |
| Smina 2020.12.10 | Vina 分支，默认评分有修正，能量最小化更稳健 | Vina / QuickVina 卡死或结果异常 |

- 首选引擎连续 **20 分钟没有任何输出** 会被判定为卡死并终止。若“设置 →
  引擎回退”开启（默认开启），程序会按 Vina → QuickVina 2 → Smina 的顺序
  改用其他可用引擎重试，并在该组结果的说明中记录。
- 实际使用的引擎、版本与参数会写入结果元数据和 HTML 报告，便于复现。
- 不同引擎的评分函数不完全相同，分数不宜跨引擎直接比较；同一批筛选应尽量
  使用同一引擎。QuickVina 2 与 Vina 使用相同评分函数，结果更具可比性。
- 三个引擎的可执行文件可在“设置”中分别指定；Windows 安装包已内置，
  macOS / Linux 可安装到系统 `PATH` 或在设置中指定。

### 搜索盒子

盒子决定对接引擎在靶点结构的哪个区域寻找结合位置。对每个靶点，程序按以下逻辑给出建议：

1. **几何口袋**：在靶点表面扫描足够深、足够封闭、且与外部溶剂连通的空腔，
   用包埋度、体积、紧密度等指标排序（蛋白、核酸与多肽都适用）。
2. **实验位点校验**：如果结构里有共晶配体或 `SITE` 记录，程序会检查几何口袋
   是否与实验位点重合。重合时使用“口袋 + 实验位点”的联合盒子，确保覆盖已知
   配体；不重合或没有可靠口袋时，回退到共晶配体 / `SITE` 位点。
3. **无实验信息的结构**：使用置信度最高的几何口袋；都没有时才使用全结构盲对接。
4. **小分子靶点**：以目标分子为中心，按两侧分子尺寸估算盒子。
5. **手动指定**：在 3D 视图中拖动，或在右侧输入中心坐标和边长；手动设置始终优先。

自动结果并非在所有场景下都可靠：多肽靶点常常没有可识别的几何口袋，小分子靶点
也只能按尺寸估算。这两种情况下，列表会把盒子标为“自动结果不可靠，请手动确认”，
点击“开始对接”时也会先提示你设置盒子中心与边长，而不是直接使用盲对接盒子。

点击“设置盒子”会打开 3D 编辑器，打开时默认显示上面的自动推荐结果：

- **观察**：左键拖动旋转，滚轮缩放，右键拖动平移。橙色线框是搜索盒子，
  白色圆环是盒子中心（中空设计，不会挡住中心的配体）。蛋白与核酸以卡通模型
  显示，配体、辅因子与离子为元素着色的球棍模型；勾选“显示原子点”可叠加所有
  重原子。
- **移动盒子**：拖动白色中心圆环，或勾选“点击结构设置盒子中心”后点击结构上的
  任意原子，盒子中心会移到该位置。
- **调整大小**：拖动红、绿、蓝三色面点分别调整 X、Y、Z 边长（深色点对应负方向）。
  默认保持对侧面不动；按住 **Shift** 拖动时盒子中心保持不变，两侧同时伸缩。
- **精确输入**：右侧“中心”和“边长”输入框与 3D 视图双向同步。
- **视角**：“聚焦盒子”把镜头移到盒子附近；“重置视角”回到整个结构。
- **恢复推荐**：点击“使用推荐盒子”放弃手动修改，恢复自动结果。
- **洞察模式**：默认关闭，3D 显示与之前一致。点击右上角的“洞察模式”按钮后，
  编辑器会列出结构中的实验证据与候选分子性质，并叠加到 3D 视图：共晶配体为
  品红色球棍，`SITE` 记录中的残基为青色棒状，搜索盒子仍是橙色线框。共晶配体
  与实验位点通常是最可靠的结合位置，建议把盒子中心放在这些彩色区域附近；
  候选分子一行会给出重原子数与可旋转键（柔性键）数量，以及覆盖该分子所需的
  最小盒子边长。当前盒子小于该建议值时，界面会标出被压缩的坐标方向。再次
  点击“关闭洞察”即可隐藏参考层，恢复原有显示。OpenGL 回退视图不支持叠加
  显示，但文字信息仍然可用。

3D 视图由内置的 NGL Viewer（MIT 许可）在本地渲染，不联网，效果接近 PyMOL。
如果电脑无法初始化内嵌浏览器（QtWebEngine），程序会自动回退到内置的 OpenGL
视图；两者都不可用时，3D 区域会显示提示，右侧数值输入与保存仍可正常使用。

自动推荐的盒子边长限制在 18–60 Å；手动设置允许 5–150 Å。盒子过小会漏掉真实
构象，过大则增加计算量并降低精度。界面会显示来源、体积与判断依据。

### 对接参数

| 参数 | 默认值 | 含义 | 建议 |
| --- | --- | --- | --- |
| 搜索强度（exhaustiveness） | 16 | 搜索的彻底程度 | 初次筛选 8，正式计算 16–32 |
| 输出构象数（num_modes） | 9 | 每个分子保留多少个结合姿态 | 一般 9 足够 |
| 能量范围（energy_range） | 3.0 kcal/mol | 输出构象与最优构象的最大能量差 | 保持默认 |
| 随机种子（seed） | 42 | 固定后结果可复现 | 需要复现时不要改 |
| CPU 核心数 | 0（全部） | 同时使用的核心数 | 运行其他程序时可留一半 |

搜索强度越高、盒子越大，耗时越长。可以先用较小参数试跑，再对重点分子提高参数。

## 第 5 步：运行与结果

点击“开始对接”。程序会显示进度、当前分子和运行日志，可随时取消。

结果页包含：

- **最佳打分**：所有成功结果中的最低结合能，单位 kcal/mol。
- **结果表**：每个“靶点 + 候选分子”组合的对接类型、最优打分、构象数、盒子来源、耗时与说明。
- **图表**：结合能热图与柱状图，便于横向比较。
- **编辑热图**：热图生成后，图表下方有“编辑热图”按钮。可以逐个修改靶点和
  候选分子的显示名称、标题与副标题，选择蓝色 / 绿色 / 青色 / 橙色 / 紫色 /
  灰度配色，并选择输出 PNG、PNG + SVG（矢量，适合在 Illustrator / PPT 中
  继续改字）或 PNG + PDF（打印）。设置随项目保存，重新生成报告时仍然生效。
- **报告**：生成一个自包含的 HTML 文件，可离线打开或直接发送给合作者。
- **PyMOL**：为结果生成 `.pml` 脚本，安装 PyMOL 后可打开查看复合物。
- **导出**：CSV 结果表和复合物结构保存在项目目录中。

分数越负表示程序预测的结合越有利，但不同靶点、不同参数之间的分数不能直接
当作实验亲和力比较。报告中附有方法与参数说明，写论文时应一并引用。

## 第 6 步（可选）：PyMOL 渲染

对接完成后，侧栏的“PyMOL 渲染”页面可以把现有的风格脚本套用到复合物上，
直接导出 PNG。它不会把 PyMOL 加载进主程序，而是在后台启动独立的
`pymol -cq` 进程；渲染失败或卡住只会影响这一次出图，不会带走界面。

使用前需要本机已安装 PyMOL。程序会先查找当前 Python 环境中的 PyMOL
（conda 环境通常是 `Scripts\pymol.exe`），再查找系统安装；也可以点击
“设置与环境检查”，在“PyMOL 可执行文件”一栏手动指定。安装包不内置 PyMOL。

页面按以下顺序操作：

1. **选择复合物**：列出项目 `complexes/` 中已有的靶点–配体复合物，并显示
   对应的最佳打分（如果有）。
2. **选择风格脚本**：选择一个文件夹，程序会递归找出其中所有 `.pml` 与 `.txt`。
   可以按住 Ctrl/Shift 一次选中多个脚本，它们会按列表顺序依次渲染。
3. **选择分辨率**：900（快速预览）、1200（标准）、1800（高清）或 2400（打印）。
   无界面渲染始终使用光线追踪；脚本里带透明表面的，耗时通常更长。
   **标签字号**默认“大”：PyMOL 的残基编号与氢键距离文字按固定像素绘制，
   分辨率越高相对越小，程序会以 900 像素为基准自动补偿，并把脚本里的
   `label_size` 按同一倍数放大。如果觉得字太大，可以选“标准”，它只做
   分辨率补偿、不再额外放大。
4. 点击“渲染所选脚本”，完成后在下方预览；可打开图片或在文件夹中定位。
   图片保存在项目的 `pymol/renders/` 目录，文件名包含靶点、配体与脚本标签。

风格脚本应只包含样式命令，例如 `show cartoon`、`color`、`set`、`select`。
加载结构、显示视角、调用 `ray` 和保存 PNG 由程序自动补充，因此脚本里不需要
（也不要）再写 `load`、`ray`、`png` 或 `quit`。脚本可以带中文注释和中文路径，
程序会在临时目录中按 PyMOL 能读取的系统编码转写后再执行。

点击“取消”会结束整个 PyMOL 进程树，包括启动器派生出的子进程。分辨率越高、
脚本越复杂，耗时越长；如果长时间没有结果，可先降低分辨率，或在展开的
运行日志中查看 PyMOL 的输出。

## 工作目录内容

```text
项目名/
  project.json        项目清单（名称、条目、状态、盒子设置）
  inputs/             你导入的原始结构
  prepared/           准备后的靶点与候选分子
  boxes/              每个靶点的盒子设置
  docking/            Vina 输出与日志
  complexes/          靶点-候选分子复合物
  analysis/           结果表、热图、图表设置、汇总 JSON
  report/             HTML 报告
  pymol/              PyMOL 脚本
  pymol/renders/      用风格脚本渲染的 PNG
  logs/               项目内运行日志
```

不要手动重命名 `prepared/`、`docking/` 里的文件；如需整理，请在界面中删除条目。
删除条目时界面会提示受影响的文件范围。

## 常见问题

**程序提示找不到某个对接引擎。**
Windows 安装包已内置 AutoDock Vina、QuickVina 2 与 Smina。macOS/Linux 需安装
对应程序并确保在 `PATH` 中，或在“设置”里分别指定可执行文件。即使只找到一个
引擎，也可以正常对接。

**准备时提示移除了金属离子。**
多数金属离子不参与 Vina 打分，保留会导致原子类型错误，因此默认移除。若研究需要
金属配位，请在准备后检查结构，并用其他工具单独处理。

**提示补全了缺失残基。**
晶体结构常有柔性环缺失。程序用 PDBFixer 补全，可能影响局部构象；关键位点建议
对照原始结构确认。

**盒子自动推断不合理。**
几何口袋适合寻找蛋白表面的天然空腔，但柔性蛋白、膜蛋白或构象变化较大时可能
偏离真实位点。此时打开“编辑盒子”，在 3D 视图中直接拖动盒子，或点击结构上的
原子设置中心；也可以参考共晶配体或文献坐标精确输入。还可以先用较大的盲对接
盒子探索，再缩小范围精算。

**3D 盒子视图是空白的。**
程序优先用内嵌的 NGL Viewer 渲染，需要可用的显卡驱动；失败时会自动回退到
OpenGL 视图。虚拟机、远程桌面或老显卡驱动可能两者都不可用，此时右侧的数值
输入仍可正常使用。更新显卡驱动，或在物理机上运行通常可以恢复。若只是旋转
卡顿，取消勾选“显示原子点”即可。

**“PyMOL 渲染”页面提示未检测到 PyMOL。**
安装包不内置 PyMOL。请先安装开源版 PyMOL，然后在“设置与环境检查”中指定
`pymol.exe`（Windows）或 `pymol`（macOS/Linux），或设置环境变量
`PYMOL_RENDER_EXE`。这一提示不影响对接与结果报告。

**PyMOL 渲染一直没有结果。**
先查看运行日志：如果日志停在 `Ray:` 之前，通常是脚本中的选择或命令有误；
可以只保留一个脚本并降低到 900 像素重试。若日志很长且 CPU 持续占用，说明
复杂表面样式的光线追踪确实较慢，请继续等待或点击“取消”。取消会结束整个
PyMOL 进程树，不会留下后台进程。

**对接失败或分数异常。**
查看结果表“说明”列和 `logs/session.log`。常见原因：盒子不包含配体、配体电荷/
质子化状态异常、PDBQT 原子类型不支持、结构中有未知残基。如果首选引擎长时间
没有输出，程序会在 20 分钟后终止它并自动改用其他引擎；结果说明中会记录这次
回退，最终分数来自实际完成的那个引擎。

**为什么打分比之前的软件低？**
对接打分是同一程序内部用于排序的经验分数，不是实验结合自由能。不同软件或
引擎版本、不同评分函数（Vina、Vinardo、AutoDock4 等）、受体/配体预处理、
是否保留水与金属离子、盒子范围都会改变数值，因此不能直接横向比较。Smina
的默认评分在 Vina 基础上做了修正，Smina 与 Vina / QuickVina 2 的分数尤其
不宜混用。小分子
片段（例如阿司匹林）通常只有约 −4 到 −6 kcal/mol；较大的类药分子常见
−6 到 −10 kcal/mol。判断结果时应关注同一批分子的相对排序、重对接 RMSD 和
阳性对照，而不是单个分数的大小。

**能对蛋白质–蛋白质或蛋白–多肽吗？**
本地版本暂不提供。Vina 的评分函数与搜索算法面向小分子配体，用于大分子界面
会得到不可靠的分数；多肽的扭转自由度也远超 Vina 能可靠搜索的范围。程序会
明确标记“不支持”，请改用 ClusPro、HADDOCK、RosettaDock 等专门工具。

**DNA/RNA 与小分子的结果可信吗？**
流程可以运行，但 Vina 的评分函数主要基于蛋白–配体数据训练。核酸靶点应优先
参考共晶配体、NMR 结构或文献位点设置盒子，并把分数用于同一靶点内的相对排序，
不要当作绝对亲和力。

**为什么无共晶配体的结构打分很低？**
有些 PDB 的 `SITE` 记录标的是金属结合位点（例如 1BCI 的钙结合环），而不是
药物结合口袋。程序仍会按实验位点推荐盒子，但如果候选分子与该位点无关，低分
是正常结果。此类靶点建议使用带共晶配体的结构，或根据文献手动设置盒子。

**中文路径会有问题吗？**
程序会把 Vina/OpenBabel 的计算放在纯 ASCII 临时目录中，完成后再复制回项目，
因此工作目录可以包含中文。仍建议避免超长路径和特殊符号。

**如何备份或迁移项目？**
关闭程序后复制整个工作目录即可。用户设置位于 `%APPDATA%\DockFlowLab\settings.json`
（Windows），日志位于 `%LOCALAPPDATA%\DockFlowLab\logs`。
